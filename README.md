# Personal Portfolio Website

## Description
This is a simple and responsive personal portfolio website built with HTML, CSS, and JavaScript. It includes sections for an introduction, projects, and a contact form, along with an 'About Me' section and social media links.

## Features
- Smooth scrolling navigation
- Responsive design
- Project showcase with modals for details
- Contact form
- Social media icons

## Folder Structure
```
/portfolio-project
│── index.html
│── styles.css
│── script.js
│── images/
│   ├── profile-pic.jpg
│   ├── project1-img.jpg
│   ├── ... (additional images)
```

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/portfolio-project.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in a browser to preview.

## Usage
- Modify `index.html` to update text and images.
- Customize styles in `styles.css`.
- Update `script.js` for additional interactivity.
